## What this is

This is the scaffold page for the AlmiCV **Learn** system. Every guide that follows
is one markdown file in `content/learn/`, and that directory is the only place the
routes, this hub and the sitemap read from — so a guide cannot exist without being
linked, and cannot be linked without existing.

## What each guide gives you

- **What actually matters** for that part of a CV, in plain words.
- **The mistakes that cost the most**, with the correction next to each one.
- **A link straight into the builder or the template** it was written for.

## An honest note

AlmiCV's ATS score is a structural check on your document, not a prediction of any
employer's decision. Conventions marked "regional default" are exactly that — verify
with your target employer for each application.

> Replace this page once the first authored guide lands. It is here so the content
> gate has a file to check — a build with an empty `content/learn/` fails on purpose.
